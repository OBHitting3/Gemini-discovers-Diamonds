# Manus handoff notes (Tier 2 meshes)

When Karl asks for a **real uploaded mesh** (not procedural Parts), Cursor writes a note here:

`YYYY-MM-DD_<slug>-handoff.md`

Template sections:

1. **Slug** — matches `ItemCatalog` / `ProceduralAssetCatalog` id  
2. **Description** — MCM style, size, colors  
3. **Files needed** — paths under `vendor-imports/_incoming/`  
4. **Roblox** — MeshPart vs Model, estimated part count, CollectionService tags  
5. **asset-index.yaml** — example entry after upload  

Karl does not run upload commands; Manus or Eddie completes Tier 2.
